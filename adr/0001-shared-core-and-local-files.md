# ADR-0001：共享 Rust 核心与本地文件架构

- 状态：已接受
- 日期：2026-07-25

## 背景

司命需要同时提供桌面编辑器和无界面 CLI，并保证两种入口对同一项目产生相同的诊断、迁移和导出结果。项目还必须适合 Git 管理，不能依赖本机数据库或云端服务。

## 决策

采用 Rust Workspace：

- `siming-core` 定义权威数据模型和领域规则，不依赖 UI 与文件选择器。
- `siming-storage` 负责路径边界、原子写入、备份和外部修改检测。
- `siming-cli` 与 Tauri 桌面端调用同一套核心和存储 crate。
- 项目源文件使用带版本号的 JSON；共享相对路径写入 `.siming/project.json`。
- React 只负责界面和即时交互提示，不复制权威校验与导出逻辑。

## 结果

- GUI 与 CLI 可以通过固定 fixtures 做契约对照测试。
- 项目可直接纳入版本控制并跨平台移动。
- 前端原型数据必须经过 IPC 进入共享核心，不能成为第二套业务模型。
- 首期需要维护 Rust、TypeScript 和 JSON Schema 的契约同步测试。
