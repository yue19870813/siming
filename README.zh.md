# 司命（Siming）

掌管命运与叙事走向的跨平台剧情对话编辑器。

项目已经完成技术方案中的阶段 0 工程基线，包含：

- React 19、TypeScript、Vite、Tailwind CSS 4 与 Tauri 2 桌面应用。
- Rust Workspace、共享核心、存储边界和独立 `siming` CLI。
- 版本化 JSON Schema、固定契约样例与架构决策记录。
- 前端测试、Rust 测试、格式化、Lint、Clippy 和三平台 CI。
