# Shared SDK behavior contracts

`bundled/` and `directory-chunks/` are generated by the repository's Rust CLI. Do not edit these exports by hand.

`behavior.json` is produced by the Rust simulator through `tests/RustReference`. It records node-entry order, ordered host messages, custom business events and final variables for each scenario. Built-in variable events appear in the node trace and final variables, but are excluded from the custom event callback list. The C# tests read this language-independent file; future C++ and JS SDKs can consume the same input and assertions.

Regenerate from the repository root:

```sh
python3 sdks/csharp/scripts/generate-contracts.py
python3 sdks/csharp/scripts/unity-metadata.py
```

The simulator executes custom events as no-op successful callbacks. C#-specific async completion, cancellation, timing and restore tests live in the C# test runner.
