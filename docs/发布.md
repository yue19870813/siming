# 发布 Siming

在 GitHub Actions 的 **Release** 工作流中选择 `Run workflow`，输入 `1.2.3` 或 `1.2.3-beta.1`。工作流会校验干净工作区和 Tag，统一更新 Cargo、Tauri、C#、Unity 版本，提交 `chore(release): prepare v<version>`，创建 Tag，并构建 GitHub Release。

Release 包含 Windows x64、macOS Intel、macOS Apple Silicon 安装包，以及 Unity `.tgz` 和两个 NuGet `.nupkg`。预发布版本自动标记为 Pre-release；当前安装包未签名。

Intel macOS 使用 `macos-15-intel` runner。桌面附件仅收集 Windows `.msi` / NSIS `.exe` 和 macOS `.dmg`，不上传 `.app` 目录或内部文件（应用包含在 DMG 内）。安装包附件名添加平台和架构前缀，SDK 保留原包名。创建 Tag 前检查各平台产物和 SDK 包是否齐全、附件名是否重复；上传不覆盖已有同名附件。

Unity 可使用版本固定的 Git URL：

```text
https://github.com/yue19870813/siming.git?path=/sdks/csharp/Packages/dev.siming.sdk#v1.2.3
```

SDK 也可从 Release 下载 `.tgz` 与 `.nupkg`。构建失败时不会创建 Release；版本提交和 Tag 已产生时，应检查日志后修复并重新运行后续构建。
